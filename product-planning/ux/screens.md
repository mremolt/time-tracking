# Screens that are not drawn

They use the shell, the building blocks (`shell.md`) and these patterns.

| Screen | Pattern |
|---|---|
| **Day** (any date; B-01, B-03, B-04, B-18) | Date picker with previous/next; day view (timeline + entries table as on Today) with edit/delete; "Record a working day" (manual start/end/breaks) in a **dialog**. Reached from the Day \| Week switch and from Today. No timers here (they are on Today). |
| Absences | Page header, calendar or list card, "Mark absence" in a dialog |
| Balance & summary | Figure tiles (target, worked, balance), month table, totals per project. The month view lives here (D-17) |
| Reports (all) | Page header, filter row as on the dashboard, results in a styled table card, export menu |
| Budgets | Table card with usage bars and status chips as on the dashboard |
| Admin pages | Group tabs (`shell.md`), table card with the main action in the page header; create/edit in a dialog or a form page with clear sections – never several unrelated forms on one page |
| Settings | Cards: language, theme (System / Light / Dark), default project, preferred view, notifications |
| Login, invitation, password reset | Same theme and tokens as the app |
| Help & guide, My data, Audit log | Page header plus cards / table card |
